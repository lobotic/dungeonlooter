# 🏰 Dungeon Looter

A daily dungeon crawler inspired by classic puzzle games.

Every day a new dungeon is generated. Choose your hero, read the clues, avoid monsters and traps, find the treasure, and escape alive.

🎮 Play:
https://lobotic.github.io/dungeonlooter/

---

## Features

- 🗓️ One handcrafted-style dungeon every day
- 🛡️ Three unique heroes
- 🔮 Logic-based clues
- 👹 Multiple monster types
- 🪤 Deadly traps
- 💰 Treasure and gold
- 📜 Magic scrolls
- ☠️ Mark suspicious tiles
- 📈 Daily statistics and win streaks
- 💾 Saves your progress if you refresh the page

---

## How to play

- Reach the exit alive.
- Read the clues carefully.
- Monsters deal different amounts of damage depending on your hero.
- Traps always deal damage.
- Treasure gives gold.
- Dragons drop gold and scrolls.
- Scrolls reveal any hidden tile.
- Flags help you remember dangerous locations.
- Only one dungeon can be completed each day.
